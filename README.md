# Custom Mouse

A simple client-side Fabric mod for Minecraft 1.21.11.

## Features

- Press **P** to open the Custom Mouse menu.
- Change mouse sensitivity.
- Toggle inverted mouse Y.
- Change crosshair color.
- Change crosshair size, thickness, and gap.
- Settings apply immediately while Minecraft is running.

## Build

Use Java 21 and run `gradlew build` from the project folder. The finished mod JAR will be in `build/libs/`.
